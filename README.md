# 📘 جزوهٔ شب امتحانی — آداب پزشکی ۱ | HumsYar

جزوهٔ مرتب و فشردهٔ درس «آداب پزشکی ۱» (دانشگاه علوم پزشکی هرمزگان) که به‌صورت خودکار از روی اسلایدهای اساتید، جزوهٔ دست‌نویس کلاس و سند رسمی توانمندی‌ها ساخته شده است.

تهیه‌شده با **HumsYar** — دستیار هوشمند دانشجویان پزشکی.

## ⬇️ دانلود

آخرین نسخهٔ PDF را از بخش **[Releases](../../releases/latest)** دانلود کنید، یا مستقیم از خود مخزن:

**[جزوه-شب-امتحانی-آداب-پزشکی-1.pdf](./جزوه-شب-امتحانی-آداب-پزشکی-1.pdf)** — ۲۵ صفحه، شامل:

| بخش | موضوع | مدرس / منبع |
|------|-------|-------|
| فصل ۱ | شایستگی‌ها و توانمندی‌های پزشک عمومی | دکتر الهام بوشهری |
| فصل ۲ | پروفشنالیسم (تعهد حرفه‌ای) | دکتر سمیره عابدینی |
| فصل ۳ | برقراری ارتباط مؤثر و گوش دادن فعال | دکتر سمیره عابدینی |
| فصل ۴ | مهارت‌های مطالعه و یادگیری | دکتر فرحناز کمالی |
| فصل ۵ | مرور سریع شب امتحان (اعداد طلایی، اسم‌ها، لیست‌های حفظی) | — |
| ضمیمه | خلاصهٔ کامل «سند توانمندی‌های دانش‌آموختگان دکترای پزشکی عمومی» | سند مصوب شورای عالی برنامه‌ریزی علوم پزشکی |

ویژگی‌ها: لوگوی HumsYar روی جلد، نام HumsYar در پاصفحهٔ همهٔ صفحات، صفحه‌بندی تمیز (هیچ لیستی بین دو صفحه نمی‌شکند).

## 🗂 ساختار مخزن

```
├── ارشیو کامل اداب پزشکی.rar      ← آرشیو اصلی آپلودشده (RAR5)
├── جزوه-شب-امتحانی-آداب-پزشکی-1.pdf ← خروجی نهایی ⭐
├── 1669879055-127273-1-.pdf        ← سند رسمی توانمندی‌های دکترای پزشکی عمومی (منبع ضمیمه)
├── extracted/                      ← فایل‌های استخراج‌شده از آرشیو (ppt/pptx/pdf)
├── text/                           ← متن استخراج‌شده از اسلایدها و طرح درس
└── tools/
    ├── build_booklet.py            ← اسکریپت ساخت PDF (fpdf2 + HarfBuzz برای فارسی/RTL)
    ├── extract_all.py              ← استخراج متن از ppt/pptx/pdf
    ├── fonts/                      ← فونت وزیرمتن (Vazirmatn)
    ├── assets/                     ← لوگوی HumsYar و تصاویر جلد
    └── scan_pages/                 ← صفحات اسکن‌شدهٔ جزوهٔ دست‌نویس «خلاصه آداب ۱»
```

## 🔁 بازسازی PDF

```bash
pip install -r requirements.txt
python3 tools/build_booklet.py
```

> نکته: فایل «خلاصه آداب 1.pdf» اسکن CamScanner بود؛ محتوای آن از روی تصاویر صفحات خوانده و در فصل‌های ۳ و ۴ و جمع‌بندی ادغام شده است. ضمیمهٔ انتهای جزوه نیز خلاصهٔ کامل سند ۲۷ صفحه‌ایِ توانمندی‌ها (مصوب ۱۳۹۴) است.

## 📖 جزوهٔ تفسیر موضوعی قرآن — ویژهٔ برادران

جزوهٔ دوم این مخزن، یک جزوهٔ ۲۹ صفحه‌ایِ تفسیر موضوعی چهار سورهٔ **حمد، توحید، عصر و کوثر** است که فقط بر پایهٔ سه فایل HTML «تفسیر نور (حجت‌الاسلام محسن قرائتی)» موجود در همین مخزن ساخته شده است.

- 📥 **دانلود PDF:** از بخش [Releases](https://github.com/esogand15-droid/adabpezshki/releases) — تگ `tafsir-v1.0`، فایل `HumsYar_Tafsir_Mowzui_Jozve.pdf`
- آیات حرف‌به‌حرف از منبع، با قلم قرآنی AmiriQuran در بلوک‌های طلایی/کرم؛ متن فارسی با وزیرمتن
- همهٔ فهرست‌های شماره‌دار منبع با شمارش دقیق (عصر ۱۲ پیام، کوثر ۲۰ پیام، حمد ۱۱ درس تربیتی، ۱۷ آیه)
- فصل پایانی «مرور سریع شب امتحان»: آیات طلایی، اعداد طلایی، گفتاوردها، فهرست‌های حفظی و جفت‌های مقایسه‌ای

```
tafsir/
├── inventory.md                    ← فهرست‌برداری گام صفر از منابع
├── PLAN.md                         ← نقشهٔ فصل‌ها و بودجهٔ صفحات
├── QC_REPORT.md                    ← گزارش کنترل کیفیت (شمارش‌ها، ترمیم آیات، پرشدگی صفحات)
├── extracted/                      ← رونوشت متنی عین منابع HTML
├── content/                        ← محتوای فصل‌ها (۵ ماژول پایتون)
├── tools/build_tafsir.py           ← اسکریپت ساخت PDF
└── output/جزوه-تفسیر-موضوعی-قرآن.pdf
```

بازسازی: `python3 tafsir/tools/build_tafsir.py`

## 🧰 ابزارهای استفاده‌شده

- **fpdf2 + uharfbuzz** — تولید PDF با شکل‌دهی صحیح حروف فارسی و راست‌به‌چپ
- **python-pptx / olefile** — استخراج متن از اسلایدهای pptx و ppt قدیمی (باینری)
- **pdfminer.six / pypdf / pypdfium2** — استخراج متن و تصاویر از PDFها
- **unrar (کامپایل‌شده از سورس گیت‌هاب)** — استخراج آرشیو RAR5
- **فونت وزیرمتن** — [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn)
