# 📘 جزوهٔ شب امتحانی — آداب پزشکی ۱

جزوهٔ مرتب و فشردهٔ درس «آداب پزشکی ۱» (دانشگاه علوم پزشکی هرمزگان) که به‌صورت خودکار از روی اسلایدهای اساتید و جزوهٔ دست‌نویس کلاس ساخته شده است.

## 📄 خروجی نهایی

**[جزوه-شب-امتحانی-آداب-پزشکی-1.pdf](./جزوه-شب-امتحانی-آداب-پزشکی-1.pdf)** — ۱۹ صفحه، شامل:

| فصل | موضوع | مدرس |
|------|-------|-------|
| ۱ | شایستگی‌ها و توانمندی‌های پزشک عمومی | دکتر الهام بوشهری |
| ۲ | پروفشنالیسم (تعهد حرفه‌ای) | دکتر سمیره عابدینی |
| ۳ | برقراری ارتباط مؤثر و گوش دادن فعال | دکتر سمیره عابدینی |
| ۴ | مهارت‌های مطالعه و یادگیری | دکتر فرحناز کمالی |
| ۵ | مرور سریع شب امتحان (اعداد طلایی، اسم‌ها، لیست‌های حفظی، چک‌لیست) | — |

## 🗂 ساختار مخزن

```
├── ارشیو کامل اداب پزشکی.rar      ← آرشیو اصلی آپلودشده (RAR5)
├── جزوه-شب-امتحانی-آداب-پزشکی-1.pdf ← خروجی نهایی ⭐
├── extracted/                      ← فایل‌های استخراج‌شده از آرشیو (ppt/pptx/pdf)
├── text/                           ← متن استخراج‌شده از اسلایدها و طرح درس
└── tools/
    ├── build_booklet.py            ← اسکریپت ساخت PDF (fpdf2 + HarfBuzz برای فارسی/RTL)
    ├── extract_all.py              ← استخراج متن از ppt/pptx/pdf
    ├── fonts/                      ← فونت وزیرمتن (Vazirmatn)
    ├── assets/                     ← تصویر جلد
    └── scan_pages/                 ← صفحات اسکن‌شدهٔ جزوهٔ دست‌نویس «خلاصه آداب ۱»
```

## 🔁 بازسازی PDF

```bash
pip install -r requirements.txt
python3 tools/build_booklet.py
```

> نکته: فایل «خلاصه آداب 1.pdf» اسکن CamScanner بود؛ محتوای آن از روی تصاویر صفحات خوانده و در فصل‌های ۳ و ۴ و جمع‌بندی ادغام شده است.

## 🧰 ابزارهای استفاده‌شده

- **fpdf2 + uharfbuzz** — تولید PDF با شکل‌دهی صحیح حروف فارسی و راست‌به‌چپ
- **python-pptx / olefile** — استخراج متن از اسلایدهای pptx و ppt قدیمی (باینری)
- **pdfminer.six / pypdf** — استخراج متن و تصاویر از PDFها
- **unrar (کامپایل‌شده از سورس گیت‌هاب)** — استخراج آرشیو RAR5
- **فونت وزیرمتن** — [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn)
