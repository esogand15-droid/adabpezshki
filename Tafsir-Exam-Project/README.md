# بانک سؤالات تفسیر موضوعی قرآن — ویژهٔ برادران (HumsYar)

سیستم کامل آزمون و مرور بر پایهٔ سؤالات «Tafsir (2).pdf»، محدودشده به چارچوب جزوهٔ
تفسیر موضوعی قرآن (ویژهٔ برادران): سوره‌های **حمد، توحید، عصر و کوثر**.

## شروع سریع

فایل **`index.html`** را با دوبار کلیک در مرورگر باز کنید — کاملاً آفلاین کار می‌کند
(داده داخل خود فایل تزریق شده؛ نیازی به اینترنت یا سرور نیست).

امکانات: پاسخ‌دهی با بازخورد فوری (سبز/قرمز + توضیح و منبع زیر سؤال)، آزمون تصادفی با
تعداد دلخواه، بخش سؤالات قطعی/مفهومی، مرور اشتباهات، نشان‌کردن سؤال، جست‌وجو و فیلتر
(مبحث/دشواری/وضعیت)، گزارش پیشرفت به تفکیک مباحث جزوه، حالت شب/روز — همه با ذخیرهٔ
خودکار در مرورگر (localStorage).

## ساختار پروژه

```
Tafsir-Exam-Project/
├── index.html                  اپ آزمون (تک‌فایل، آفلاین)
├── data/questions.json         منبع واحد داده — ۳۰ سؤال پذیرفته‌شده
├── pdf/
│   ├── Tafsir_Mozooei_Brothers_Question_Bank.pdf    بانک با پاسخ و توضیح
│   └── Tafsir_Practice_Without_Answers.pdf          نسخهٔ تمرینی + کلید در انتها
├── reports/
│   ├── analysis_report.md      گزارش کامل تحلیل و اعتبارسنجی
│   ├── exam_sources_match_report.md  تطبیق ۲۷۰ سؤال با ۳ منبع آزمون (تفسیر نور HTML)
│   ├── coverage_report.md      پوشش مباحث جزوه و شکاف‌ها
│   └── excluded_questions.csv  ۲۴۰ سؤال خارج از محدوده + علت حذف
├── assets/                     (رزرو)
├── tools/                      اسکریپت‌های بازتولید (پایتون ۳ + fpdf2==2.8.8)
└── README.md
```

## خلاصهٔ اعداد

- کل سؤالات منبع: **۲۷۰** → پذیرفته: **۳۰** (۲۲ قطعی A + ۸ مفهومی B) · خارج از محدوده: **۲۴۰** · تکراری/ساختگی: ۰
- فقط درس نهم منبع (سورهٔ حمد) در محدودهٔ جزوه است؛ **منبع هیچ سؤالی برای توحید، عصر و کوثر ندارد** (ر.ک. coverage_report.md) و طبق قاعدهٔ پروژه سؤالی ساخته نشده است.

## بازتولید خروجی‌ها

```bash
pip install fpdf2==2.8.8 uharfbuzz pypdfium2
python3 tools/extract_source.py   # استخراج ۲۷۰ سؤال از Tafsir (2).pdf (ریشهٔ مخزن)
python3 tools/build_dataset.py    # data/questions.json + excluded_questions.csv (+QC تراز)
python3 tools/build_html.py       # index.html
python3 tools/build_pdfs.py       # دو PDF
```
